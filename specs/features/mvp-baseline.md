## 产品端

### `PLAT-01` 用户和摄影师工作区

普通用户和摄影师使用同一个微信小程序客户端和账号体系，根据账号角色展示各自工作区。摄影师身份通过入驻申请获得。

**验收场景**

- Given 用户尚未申请摄影师身份，When 用户进入小程序，Then 可使用普通用户功能，且不显示已审核摄影师的接单管理能力。
- Given 用户的摄影师申请已审核通过，When 用户进入小程序，Then 可进入摄影师工作区，原普通用户身份和能力仍可使用。

### `PLAT-02` 管理员 Web 后台

管理员通过独立 Web 管理后台处理摄影师审核及平台管理任务。

**验收场景**

- Given 当前账号不是管理员，When 其请求管理员页面或管理 API，Then 系统拒绝访问。

## 摄影师入驻与服务

### `PHOTO-01` 五套作品人工审核

摄影师申请公开接单前，必须提交至少五套作品并通过人工审核。未通过审核的摄影师不得公开接单。

**验收场景**

- Given 摄影师提交少于五套作品，When 尝试提交入驻审核，Then 系统不接受该申请并提示补充作品。
- Given 摄影师已提交至少五套作品且申请仍在审核中，When 用户浏览公开摄影师列表，Then 该摄影师不作为可接单摄影师公开展示。
- Given 管理员审核通过摄影师申请，When 审核状态生效，Then 摄影师可以公开展示主页并使用接单能力。

### `PACK-01` 套餐交付信息

每个可预约套餐必须明确展示服务名称/场景、价格、拍摄时长、交付内容、套餐包含的精修照片张数和额外精修每张的价格。

**验收场景**

- Given 摄影师创建或发布套餐时未填写包含精修张数或加修单价，When 提交保存/发布，Then 系统要求补齐必填信息。
- Given 用户查看套餐，When 进入预约确认前，Then 可看到以上套餐信息及相应费用。

## 档期与撮合

### `AVAIL-01` 只维护不可约时间

摄影师在设定的可预约日期范围内默认可约，只需登记不可约时间。不可约粒度支持全天、上午、下午或自定义起止时间。已确认并支付定金的预约占用对应档期。

**验收场景**

- Given 日期在摄影师设定的可预约范围内且没有不可约记录或有效预约，When 用户查看档期，Then 该时间显示可约。
- Given 摄影师设置某日期全天不可约，When 用户查看该日期，Then 不显示为可预约。
- Given 摄影师设置上午、下午或自定义时间段不可约，When 用户查询与该时间重叠的预约时段，Then 系统拒绝该预约。
- Given 预约定金已确认支付，When 用户或其他用户尝试占用相冲突的时段，Then 系统拒绝冲突预约并保持原预约占档。

### `MATCH-01` 双向撮合

普通用户既可以浏览摄影师套餐并主动发起预约，也可以发布拍摄需求由摄影师浏览并响应。摄影师响应本身不等于预约确认。

**验收场景**

- Given 用户选择摄影师套餐和可约时间，When 用户提交预约，Then 系统创建相应预约流程。
- Given 用户发布拍摄需求，When 符合接单资格的摄影师提交方案响应，Then 用户可以查看并选择响应。
- Given 用户选择摄影师对需求的响应，When 尚未完成预约确认及定金支付，Then 档期不视为已锁定。

## 私信

### `MSG-01` 预约前后纯文字私信

用户与摄影师可在预约前及预约后通过平台私信沟通。首版只支持文字消息，不支持照片或文件。

**验收场景**

- Given 用户从摄影师主页或需求响应页发起会话，When 摄影师可接收该用户消息，Then 双方可以在平台查看和发送文字消息。
- Given 用户与摄影师已有预约，When 预约双方打开对应会话，Then 双方可继续发送文字消息。
- Given 用户尝试在私信中附加图片或文件，When 提交消息，Then 系统不提供该能力并拒绝附件内容。
- Given 非会话成员请求读取或发送该会话消息，When 服务端鉴权，Then 系统拒绝操作。

## 预约、支付与交付

### `BOOK-01` 固定比例定金

平台固定按订单结算金额的 10% 计算用户预约定金，摄影师不能修改比例。只有已满足平台保证金条件的摄影师，才可要求用户支付定金锁定档期。

**验收场景**

- Given 摄影师满足有效保证金资格，When 创建预约付款信息，Then 服务端按订单结算金额的 10% 计算应付定金。
- Given 摄影师不满足有效保证金资格，When 创建要求用户支付定金的预约，Then 系统拒绝该操作。
- Given 定金支付尚未被服务端确认为成功，When 客户端收到支付页面返回，Then 系统不将预约标记为已锁档。

保证金金额、退还/冻结/扣除规则及资金处理模式未定；这些场景只有规则确认后才能完整实现和验收。

### `DELIVERY-01` 选精修、付尾款、交付

拍摄完成后，用户先选择需要精修的照片，再在平台支付尾款；用户支付尾款后，摄影师交付精修照片。

**验收场景**

- Given 拍摄已完成，When 摄影师提供选片且用户确认精修选择，Then 系统按套餐包含数量和已确认的加修单价展示尾款。
- Given 用户尚未成功支付尾款，When 摄影师尝试将精修照片标记为已交付，Then 系统不允许完成交付状态变更。
- Given 尾款支付已由服务端确认为成功，When 摄影师交付精修照片，Then 用户可在订单中访问该交付，订单记录交付状态。

选片期限、交付期限、定金/尾款退款和摄影师结算方式仍待决策。

## 当前阻塞产品规则

- 摄影师保证金金额、缴纳渠道、退还/冻结/扣除和申诉规则。
- 预约取消、改期、退款、违约和定金归属。
- 待支付订单是否临时占档及占档时长。
- 支付渠道适用的商户准入和平台/摄影师结算模式。
- 每个套餐的精修数量和加修单价由摄影师设置；选片期限和交付期限待确认。
- 私信会话发起限制、拉黑/举报细节和消息保留期限。

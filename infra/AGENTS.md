# 基础设施规范

- 此目录保存 Docker、本地开发、部署、CI、监控和运维配置，不放业务逻辑或密钥。
- 技术方向为 Docker 化模块化单体；生产云厂商、地域、预算与备案尚未确定，部署模板不得假设已经选定。
- 本地 Compose 中的数据库使用 MySQL，并与应用 Flyway 配置一致。
- 示例环境变量放 `.env.example`，真实 `.env`、密钥、证书和支付私钥不得提交。
- 对象存储桶默认私有；部署文档明确公开作品与私密订单照片的授权策略。
- 为数据库和上传素材提供备份/恢复说明；任何破坏性命令必须显式确认目标环境。
- 支付回调服务必须可通过 HTTPS 访问；生产部署前验证域名、证书、回调连通性和日志脱敏。

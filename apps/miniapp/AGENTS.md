# 微信小程序规范（用户端 + 摄影师端）

- 本项目是一个微信小程序，承载普通用户和摄影师两个角色工作区，不拆成两个小程序。
- 技术方向：Taro、React、TypeScript；平台特有能力集中在适配层，避免业务页面散布平台判断。
- 页面按用户、摄影师和公共流程组织；登录后根据服务端账号角色与审核状态展示可用入口。
- 普通用户流程包括摄影师发现、作品/套餐查看、需求发布、预约、文字私信、支付、选片和精修交付查看。
- 摄影师流程包括入驻申请、上传作品、套餐管理、不可约时间、需求响应、预约管理、文字私信、选片与精修交付。
- 私信仅支持文字，严禁提供照片或文件发送控件、上传 API 调用或附件预览。
- 图片上传仅用于规格允许的作品、选片和成片交付流程；不得把私信限制误解为禁用业务图片。
- 登录身份、审核状态、保证金资格、价格、定金和订单状态均以服务端响应为准。
- 微信支付由后端创建支付参数并确认支付结果；不得因小程序支付 API 的客户端成功回调就直接确认订单。
- 作品原图、选片和精修照片使用私密访问方式；不在页面、日志或分享链接暴露永久公开地址。
- 适配小屏、弱网和上传失败；表单保持简短，明确显示套餐与费用。
- 前端 API 类型与 OpenAPI 定义保持同步。

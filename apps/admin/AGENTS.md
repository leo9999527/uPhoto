# 管理员 Web 后台规范

- 技术方向：Next.js、React、TypeScript；后台只供授权管理员在 Web 浏览器使用。
- 后台 MVP 功能包括摄影师入驻/作品人工审核、用户和摄影师基本管理、内容/举报处理、订单与支付状态查询、管理审计。
- 所有管理 API 必须在后端校验管理员身份和权限；隐藏按钮不等于权限控制。
- 审核通过、驳回、下架、冻结等操作需展示目标对象和影响，并由服务端写入审计记录。
- 私密照片和用户资料只在处理业务所需时展示；不得生成公开永久访问地址。
- 不在后台人工修改支付结果或伪造支付成功；资金问题走明确的支付/对账流程。
- 表格需具备合理分页、筛选、加载、空态和失败提示；破坏性操作需二次确认。
- OpenAPI 变更后同步维护客户端类型。
